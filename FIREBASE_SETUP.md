# Firebase (AI Studio / manual)

1. Open `firebase-applet-config.json` and replace `YOUR_*` placeholders with your Firebase **Web app** config.
2. Enable **Cloud Firestore** in the Firebase console.
3. Deploy rules from `firestore.rules`.
4. Optional: deploy `functions/` (Blaze) for Telegram/Twitter task verification + set tokens in Admin → Settings.

Full architecture notes: see **AI_GUIDE.md**.
